# Contributing

Before your first contribution, read the current `MASTER_RULES.md` in full, then read `AGENTS.md`, applicable files under `governance/`, and any vendor-specific `VENDOR_RULES.md` for the area you will change.

By submitting code, configuration, documentation, CI/CD, infrastructure, or vendor-knowledge changes, you confirm that your contribution complies with the current `MASTER_RULES.md`.

Every pull request must use the repository governance declaration and must identify authoritative sources for vendor-specific technical behavior. A plausible command or model-generated statement is not acceptable evidence.

Production-affecting changes additionally require the execution, rollback, verification, backup, and approval controls defined by project governance.
