# Documentation Policy

`MASTER_RULES.md` is authoritative.

Successful production deployment should generate an evidence-backed handover package describing the actual deployed environment, not generic vendor theory.

Required deliverables include deployment summary, implementation/change record, configuration report, as-built documentation, test evidence, security-control report, operations manual, maintenance manual, troubleshooting runbook, rollback procedure, backup manifest, and handover acceptance where applicable.

Documentation must identify authoritative knowledge/provenance, device/software version, actual state, applied changes, verification results, backup locations/digests, and known operational restrictions.
