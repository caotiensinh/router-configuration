Current 2026 guidance defines Cloud-Based, Hardware, and Software Controllers. Cloud-Based Controller runs in the cloud and emphasizes centralized management/zero-touch provisioning without on-premises controller installation. Hardware and Software Controller are on-premises controller forms with cloud access; Software Controller runs on a PC/server while Hardware Controller embeds the controller software.

## Safety boundaries

- Similar web interfaces do not prove feature parity.
- Device compatibility must be resolved per controller type/version; Cloud-Based compatibility cannot be inferred from on-premises support.
- Cloud access to an on-premises controller is not the same architecture as Cloud-Based Controller.
- Integrated gateway controller functions are a distinct category in the current comparison guide.
- Migration/backup/API semantics must be sourced separately; do not synthesize them from deployment architecture.
