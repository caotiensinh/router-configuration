## Diagnostic planes

- L3 interface/SVI state and addressing.
- Connected routes versus configured static routes.
- Destination prefix, next hop/interface and route distance/priority.
- Gateway reachability and return-path reachability.
- ARP/neighbor resolution as a dependency, not a route itself.
- Policy routing/PBR is separate from ordinary static routing.
- Network Check, packet capture and terminal observations are evidence sources, not configuration state.

## Minimum-check strategy draft

1. Confirm interface/link and expected IP/mask.
2. Confirm intended connected/static route exists and is active.
3. Confirm next-hop reachability from the correct source/interface.
4. Confirm return route on upstream/downstream peer.
5. Check overlapping/more-specific routes and administrative preference.
6. Check ACL/firewall/NAT/PBR only after route-plane evidence is collected.
7. Use ping/traceroute/network-check/packet capture as corroborating evidence.

## PASS boundary

A configured route is not PASS until representative traffic follows the intended path and management connectivity remains healthy. Missing return path must be reported separately from forward-route configuration.
