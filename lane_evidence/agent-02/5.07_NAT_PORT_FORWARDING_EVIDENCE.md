## Normalized state planes

- Base WAN/LAN NAT state.
- Port-forwarding rule match: source scope, WAN interface, optional WAN IP/alias, protocol and external port.
- Translation target: internal destination IP and destination port.
- Rule enable/disable state.
- DMZ is a distinct broad-forwarding behavior and must not be normalized as an ordinary single-port rule.
- WAN IP Alias / Virtual WAN applicability is separate from the forwarding rule itself.

## Safety

Port forwarding intentionally exposes an internal service to inbound WAN traffic. Compiler must require exact gateway model/firmware/mode, WAN identity, destination host/port, source restriction intent, existing conflicts, and post-change reachability/security verification. `Any` source must never be inferred when user intent is narrower.

## Verification target

PASS requires rule read-back plus a positive inbound test to the intended service and a negative test for unintended ports/sources where feasible. Rule creation alone is EXECUTED_UNVERIFIED.
